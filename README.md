## 📖 About

**Rungta Student Xchange** is a full-stack marketplace exclusively designed for students to buy, sell, and exchange pre-owned products within their college community.

The platform enables students to securely list products, connect with buyers, manage their listings, and discover affordable second-hand items through a modern, responsive interface.

---

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/MdAdnan098/RungtaStudentXchange.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---
